Demonstrating value and optimizing performance.

## 12.3 ROI Calculation Framework

### Simple ROI Formula

```
ROI = (Gains - Investment) / Investment × 100%
```

### Comprehensive Example

**Investment:**
- AI tool subscription: $6,000/year
- Implementation time: $2,000
- Training: $1,000
- **Total: $9,000**

**Gains:**
- Time saved: 15 hrs/week × $25/hr × 52 weeks = $19,500
- Error reduction: $2,000/year
- Increased revenue: $3,000/year
- **Total: $24,500**

**ROI: ($24,500 - $9,000) / $9,000 = 172%**
