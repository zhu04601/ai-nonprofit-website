# Chapter 11: Selecting and Evaluating AI Tools

Making smart technology decisions.

**Learning Objectives:** Assess needs, evaluate vendors, make informed decisions

**Time:** 4 hours

---

## 11.1 Needs Assessment

### Start with Problems, Not Solutions

**Wrong approach:** "Everyone's using AI chatbots, we should too"  
**Right approach:** "We spend 20 hours/week answering the same questions. How can we solve this?"

### Assessment Framework

**1. Identify Pain Points**
- What takes too much time?
- Where do errors occur?
- What limits our scale?
- What frustrates staff?
- Where do we lose people?

**2. Quantify Impact**
- Hours spent per week
- Cost of current approach
- Opportunity cost
- Error rates
- Staff satisfaction scores

**3. Define Success**
- Specific metrics
- Target improvements
- Timeline
- Budget

## 11.2 Vendor Evaluation

### Evaluation Criteria

| Criterion | Questions | Weight |
|-----------|-----------|--------|
| **Functionality** | Does it solve our problem? | 30% |
| **Usability** | Can staff use it easily? | 20% |
| **Integration** | Works with existing tools? | 15% |
| **Cost** | Within budget? Hidden fees? | 15% |
| **Support** | Help when needed? | 10% |
| **Security** | Meets privacy standards? | 10% |

### The Scorecard Method

Rate each vendor 1-5 on each criterion, multiply by weight, sum total.

## 11.3 Proof of Concept

### Testing Before Buying

**Steps:**
1. Start with free trial (most offer 14-30 days)
2. Define specific test scenarios
3. Involve actual users
4. Measure results
5. Document pros/cons
6. Compare to alternatives

### What to Test

✅ Core functionality  
✅ Integration with existing tools  
✅ Staff learning curve  
✅ Support responsiveness  
✅ Performance under load  
✅ Data export (can you leave?)

## 11.4 Total Cost of Ownership

### Beyond Subscription Fees

**Direct Costs:**
- Monthly/annual subscription
- Per-user fees
- Implementation fees
- Training costs
- Integration costs

**Indirect Costs:**
- Staff time to manage
- Learning curve productivity loss
- Ongoing maintenance
- Potential switching costs

### ROI Calculation

```
ROI = (Benefits - Costs) / Costs × 100%

Example:
Benefits: $20,000/year (time saved)
Costs: $5,000/year (subscription + time)
ROI = ($20,000 - $5,000) / $5,000 = 300%
```

## 11.5 Common Mistakes

❌ **Shiny Object Syndrome** - Buying because it's trendy  
❌ **Over-Engineering** - Too complex for needs  
❌ **Under-Researching** - First option seems good enough  
❌ **Ignoring Integration** - Creates data silos  
❌ **Skipping Training** - Staff won't adopt  
❌ **No Success Metrics** - Can't tell if it's working  

---

## Chapter Summary

- Start with problems, not solutions
- Use structured evaluation criteria
- Test with proof of concept
- Calculate total cost of ownership
- Avoid common selection mistakes
- Plan for implementation success
