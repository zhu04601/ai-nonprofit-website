```bash

pip install mkdocs-material

# 2. Extract and navigate
unzip ai-nonprofit-website-fixed.zip
cd ai-nonprofit-website-fixed

# 3. Preview locally
mkdocs serve

# 4. Open browser
http://127.0.0.1:8000
```

## Deploy to GitHub

```bash
# 1. Remove old files from your repo

# 2. Copy these files to your repo
cp -r * /path/to/your/ai-nonprofit-website/
```
